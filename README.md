# ⚠️ Intentionally Broken Sample Project

## 🚨 Important Notice

This project is **intentionally designed to contain incorrect patterns,
bad practices, and misconfigurations**.

👉 **It must NOT be used as a reference for real-world projects.**\
👉 **Do NOT copy code from this repository into production systems.**

This repository exists strictly for educational and evaluation purposes.

------------------------------------------------------------------------

## 🎯 Purpose of This Project

This project was created to support:

-   🧪 Technical interviews
-   🔍 Code review exercises
-   🧠 Architecture discussions
-   💬 Developer walkthroughs
-   📋 Candidate evaluation

It simulates a realistic codebase that contains issues a developer
should be able to identify and discuss.

------------------------------------------------------------------------

## 🛑 What This Project Is NOT

This repository is **not**:

-   A best-practices template
-   A production-ready starter kit
-   A recommended architecture
-   A security reference
-   A coding standard example

Some parts of the implementation are deliberately incorrect or
misleading.
